# Film Festival Management System

A desktop-based Film Festival Management System developed using Java Swing, JDBC, and MySQL. The application helps manage films, venues, screenings, attendees, ticket bookings, and awards through an easy-to-use graphical interface.

## Features

- Manage films, venues, screenings, attendees, tickets, and awards
- Perform Create, Read, Update, and Delete (CRUD) operations
- User-friendly Java Swing interface
- MySQL database integration using JDBC

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse 

## How to Run

1. Clone or download the repository.
2. Create the required MySQL database.
3. Update the database credentials in `DBConnection.java`.
4. Add the MySQL Connector/J library to the project.
5. Run `Main.java`.
